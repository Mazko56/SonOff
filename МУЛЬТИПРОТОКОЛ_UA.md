# Sonoff — автодіагностика кількох локальних протоколів, v1.3.0

## Що перевіряти на телефоні

1. Установити APK, зібраний із цього архіву в GitHub Actions, **оновленням без видалення даних** (щоб зберегти Keystore). Телефон і пристрій — в одному Wi-Fi.
2. Увімкнути «Шукати» й відкрити «Допомога → Поділитися журналом».
3. Для кожного Device ID у журналі буде: адреса, LAN type, TXT-факти, гіпотеза моделі, вибраний протокол, результат TCP/read-only HTTP, причина відмови, наявність ключа без його значення.
4. Для реальних восьми пристроїв із `error=401` очікувано `KEY_REQUIRED_BY_FIRMWARE`. Це доводить, що конкретні перевірені запити без шифрування відхилені; воно не доводить відсутності інших протоколів на інших моделях.
5. Не затискати кнопку налаштованої розетки й не видаляти її з eWeLink: це не потрібно для цього експерименту.

## Тести з двома режимами симулятора

**Зашифрований stock-LAN симулятор** — знайде, але без збереженого тестового ключа отримає 401:

```powershell
cd C:\sonoff
py -m pip install cryptography
py tests\fake_s60.py --host 0.0.0.0 --port 8081 --advertise --advertise-ip 192.168.0.102 --devicekey lab-test-key-only
```

**Відкритий DIY-симулятор** — має автоматично показати реле, відкрити управління ON/OFF без ключа:

```powershell
cd C:\sonoff
py tests\fake_s60.py --host 0.0.0.0 --port 8081 --advertise --advertise-ip 192.168.0.102 --diy
```

*Підставте актуальну IP-адресу ПК. Симулятори запускати почергово на порту 8081. Вони мають однаковий лабораторний Device ID `1000abcdef`. Не тестуйте обидва одночасно. Для переходу з encrypted на DIY рекомендовано повністю перезапустити APK/застосунок, оскільки це два альтернативні стани того самого фіктивного пристрою.*

## Межі

Відсутні Matter pairing/control, OpenEdge HTTP/MQTT/WebSocket access, BLE pairing, OAuth eWeLink, підбір ключа чи обхід захисту. Їх не можна імітувати `/zeroconf/info`. Не існує підстав обіцяти 100% роботи з будь-якою заводською Sonoff без авторизованих облікових даних. Підтвердження на фізичних розетках — лише після тесту на конкретних моделях.
