# GitHub Actions: виправлення помилки `claimLocal()` (v1.7.1)

## Діагноз

У прикріпленому логу: `AssertionError: 'onclick="claimLocal()"' not found`.
Тест очікує **стару** кнопку `claimLocal()`, якої немає в актуальному
інтерфейсі. Новий сценарій використовує `provisionDevice()` у панелі
«Допомога». Повертати `claimLocal()` не потрібно. У новому ZIP тест
`test_auto_local.py` перевіряє, що такої кнопки **немає**.

Під час накладання ZIP команда `Expand-Archive -Force` не прибирає
файли, які вже є в директорії, але відсутні у новому архіві. Тому
застарілі `tests/test_*.py` можуть продовжувати ламати CI.

## Безпечне оновлення

```powershell
cd C:\sonoff
git status --short
$zip = "$env:USERPROFILE\Downloads\Sonoff_MultiRoute_BuildFix_v1.7.1_20261119.zip"
Expand-Archive -LiteralPath $zip -DestinationPath C:\sonoff -Force
& .\scripts\sync_tests_windows.ps1 -ArchivePath $zip
py -m unittest discover -s tests -v
git add -A
git commit -m "Fix stale Sonoff UI test and validate WebView JS"
git push origin main
```

У разі незбережених змін спочатку зробіть резервну копію або commit.
Скрипт переносить застарілі тестові файли в `%TEMP%` і виводить їх шлях.
Він не змінює `.git` та вихідний код застосунку.

## Перевірка

З ZIP локально виконано 37 тестів: усі пройшли, а JavaScript із
`app/src/main/assets/index.html` пройшов `node --check`.
Повну збірку APK (`assembleDebug`) у цьому середовищі не запускали;
її запустить GitHub Actions після успіху тестів.
