Локальне підключення

Для нової розетки, яка підтримує власний режим налаштування, можна спробувати отримати доступ без eWeLink.

Увімкніть режим налаштування кнопкою на розетці. Якщо з'явиться мережа ITEAD-…, підключіть до неї телефон через налаштування Wi-Fi, а потім поверніться сюди.

Цей спосіб працює лише на прошивках з локальним AP-інтерфейсом. Для стандартної S60TPF його підтримка не підтверджена. Застосунок не скидає налаштування й не змінює прошивку.
