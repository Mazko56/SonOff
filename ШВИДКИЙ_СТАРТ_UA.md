# Встановлення Sonoff S60 Auto Local

1. Розмісти весь вміст архіву в корені свого репозиторію (папка `app`, файли `build.gradle`, `settings.gradle`, `.github`).
2. Запусти `Build Android debug APK` у GitHub Actions. Після успіху завантаж артефакт `SonoffS60Lab-debug-apk`.
3. Встанови APK на телефон. На тій самій Wi-Fi мережі застосунок автоматично виявляє eWeLink LAN-пристрої.
4. Ключ вручну не запитується. Якщо доступ уже збережено (наприклад, від попередньої версії), застосунок пробує локальне керування автоматично.
5. Якщо раніше невідома зашифрована S60TPF знайдена, але не авторизована, відображається «Очікує доступу». Без vendor cloud або підтвердженого заводського способу отримання ключа це **не полагодити простим пошуком Wi-Fi**.
6. Якщо телефон справді підключився до **режиму точки доступу сумісного Sonoff** з адресою 10.10.7.x/24, застосунок автоматично перевірить наявність інтерфейсу `/device`. Для S60TPF цей спосіб непідтверджений. **Не скидай діючу розетку задля цього тесту**.
7. У розділі «Допомога» є журнал подій і кнопка «Поділитися журналом»; ключі в журналах не зберігаються.

## Як побачити, чи усунено конкретну помилку

На домашньому Wi-Fi телефон 192.168.0.105: у журналі **не має бути** `LOCAL.PAIR.UNAVAILABLE` або `10.10.7.1` через спроби AP-підключення. Пошук Sonoff через mDNS продовжує працювати незалежно.

## Що реально не підтверджено

Повне первинне підключення нової S60TPF без eWeLink, китайських серверів та ручного ключа у заводській прошивці не має документованого гарантованого механізму. Новий вихідний код — це перевірене лабораторно виправлення помилкової AP-спроби та очищений інтерфейс, а не 100% гарантована розетка.
