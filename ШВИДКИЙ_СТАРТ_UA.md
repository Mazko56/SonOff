# Швидкий старт Sonoff S60

1. Зайди в GitHub репозиторій із вихідним кодом.
2. Замінюй файли на вміст архіву, який отримав із цим документом. Файли `.github/workflows/build-apk.yml`, `app/`, `settings.gradle` тощо повинні бути у корені репозиторію.
3. Запуш: `git add . ; git commit -m "Sonoff S60 RC1" ; git push origin main`.
4. GitHub → **Actions** → Build Android debug APK → зелена галочка → **Artifacts** → `SonoffS60Lab-debug-apk` → `app-debug.apk`.
5. Установи APK на Android і з'єднай телефон із тією ж Wi-Fi-мережею, де є **S60TPF**, попередньо підключена до eWeLink.
6. При першому захищеному підключенні власник сам вводить свій `devicekey`; без нього LAN шифрування не дозволяє керування. Жодної IP вводити не потрібно.
7. Якщо є проблеми — «Допомога» → «Поділитися журналом».

**Немає фізично перевіреної 100% гарантії**. Параметри й підтримка залежать від прошивки та мережі. Цей проєкт не примушує розетку ініціювати з'єднання із сервером телефона.
